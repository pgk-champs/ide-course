# Лидер турнира

Заверши `topScorer` — верни имя участника с наибольшим количеством очков.
Если список пуст, верни `null` — результата ещё нет, и это нормальная
ситуация, а не ошибка.

Пример:
```
topScorer(listOf(Participant("Аня", 15), Participant("Ваня", 10))) -> "Аня"
topScorer(emptyList()) -> null
```

<div class="hint" title="Как безопасно найти максимум в списке?">

Возвращаемый тип — `String?` (nullable), потому что для пустого списка
результата нет. `maxByOrNull { it.points }` возвращает `Participant?`
(`null` для пустого списка) — из него `?.name` достанет имя, тоже
безопасно вернув `null`, если объекта не было.

</div>

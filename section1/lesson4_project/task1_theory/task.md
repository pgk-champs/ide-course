# Финальный мини-проект: турнирная таблица

Три предыдущих урока — по кусочкам, этот — собирает их в одну задачу:
турнирная таблица участников чемпионата. Если что-то забылось, главы рядом:

- [Переменные и типы](https://pgk-champs.github.io/platform/docs/mobile/kotlin-vars)
- [Функции и лямбды](https://pgk-champs.github.io/platform/docs/mobile/functions-lambdas)
- [Классы и коллекции](https://pgk-champs.github.io/platform/docs/mobile/classes-collections)

В следующих трёх заданиях понадобится `data class` с полями (глава 3),
сортировка и обработка списков (глава 3), функции с понятной сигнатурой
(глава 2) и nullable-тип `String?` для случая «результата ещё нет» (глава 1,
раздел про типы).

Открой [Notes.kt](./src/Notes.kt) — маленькая демонстрация на своих данных
(не пересекается с тем, что будет в заданиях дальше).

Это теоретическое задание, тестов у него нет — жми Check, чтобы перейти дальше.

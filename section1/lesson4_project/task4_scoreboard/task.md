# Печать турнирной таблицы

Заверши `formatScoreboard` — собери таблицу участников в текст: одна строка
на участника вида `"<место>. <имя> — <очки>"`, строки разделены переводом
строки (`\n`). Участники — по очкам по убыванию, при равенстве очков — по
имени по возрастанию (как в задаче про ранжирование, но здесь пишешь
сортировку заново — задание самостоятельное). Для пустого списка верни
пустую строку `""`.

Пример:
```
formatScoreboard(listOf(
    Participant("Ваня", 10),
    Participant("Аня", 15),
)) ->
"""
1. Аня — 15
2. Ваня — 10
""".trim()

formatScoreboard(emptyList()) -> ""
```

<div class="hint" title="Как пронумеровать строки?">

`sortedWith(...)` — как в задаче про ранжирование. Дальше `withIndex()`
даёт пары «индекс, элемент» (индекс с нуля, место — `индекс + 1`).
`joinToString("\n") { ... }` собирает список строк в одну строку с
переводами строк между ними.

</div>

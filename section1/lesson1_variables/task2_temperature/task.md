# Термометр: °C → °F

Заверши `celsiusToFahrenheit` — переведи температуру из градусов Цельсия
в градусы Фаренгейта по формуле `F = C * 9 / 5 + 32`.

Примеры:
```
celsiusToFahrenheit(0.0)   -> 32.0
celsiusToFahrenheit(100.0) -> 212.0
celsiusToFahrenheit(-40.0) -> -40.0
```

<div class="hint" title="Почему 9 / 5, а не 9.0 / 5?">

`celsius` уже `Double`, так что `celsius * 9 / 5` целиком считается как `Double` —
дробная часть не потеряется. Отдельно проверь `9 / 5` в блокноте — это `Int`-деление,
и результат там `1`, а не `1.8`.

</div>

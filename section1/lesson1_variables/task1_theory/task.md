# Переменные и типы

Коротко, для памяти — полная глава с примерами и тренажёрами:
[pgk-champs.github.io/platform → Переменные и типы](https://pgk-champs.github.io/platform/docs/mobile/kotlin-vars)

- `val` — значение задаётся один раз и не меняется. `var` — можно переприсвоить.
  По умолчанию бери `val`, `var` — только если значение правда будет меняться.
- Тип пишется через двоеточие: `val age: Int = 20`. Kotlin умеет выводить тип
  сам по значению, поэтому `val age = 20` работает так же — тип всё равно `Int`.
- Основные типы: `Int` (целое), `Double` (дробное), `String` (текст),
  `Boolean` (true/false).
- Строковый шаблон: `"Привет, $name!"` подставляет значение переменной прямо
  в текст. Для выражения сложнее одного имени — фигурные скобки:
  `"Итого: ${price * count}"`.
- `Int` и `Double` — разные типы. `5 / 2` даёт `2` (целочисленное деление),
  а `5.0 / 2` — `2.5`.

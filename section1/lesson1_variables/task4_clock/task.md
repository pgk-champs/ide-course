# Секунды в таймер

Заверши `secondsToClock` — переведи общее число секунд в строку вида
`"Ч:ММ:СС"`. Минуты и секунды всегда занимают 2 разряда (дополняются нулём
слева), часы — без ведущего нуля.

Примеры:
```
secondsToClock(0)    -> "0:00:00"
secondsToClock(59)   -> "0:00:59"
secondsToClock(61)   -> "0:01:01"
secondsToClock(3661) -> "1:01:01"
secondsToClock(7325) -> "2:02:05"
```

<div class="hint" title="Как достать часы, минуты и секунды из общего числа секунд?">

Целочисленное деление (`/`) и остаток от деления (`%`) на `Int`:
`totalSeconds / 3600` — часы, `(totalSeconds % 3600) / 60` — минуты,
`totalSeconds % 60` — секунды. Дополнить число нулём слева до 2 знаков
поможет `.toString().padStart(2, '0')`.

</div>

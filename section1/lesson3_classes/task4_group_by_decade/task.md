# Книги по десятилетиям

Заверши `groupByDecade` — сгруппируй книги по десятилетию издания. Ключ —
строка вида `"1960-е"`, значение — список книг этого десятилетия в порядке
исходного списка.

Пример:
```
val library = listOf(
    Book("Дюна", "Герберт", 1965),
    Book("Мессия Дюны", "Герберт", 1969),
    Book("Кобзарь", "Шевченко", 1840),
)
groupByDecade(library) -> {
    "1960-е" to [Book("Дюна", ...), Book("Мессия Дюны", ...)],
    "1840-е" to [Book("Кобзарь", ...)],
}
```

<div class="hint" title="Как получить десятилетие из года?">

`(year / 10) * 10` даёт начало десятилетия (`1965 -> 1960`) за счёт того, что
`/` на `Int` отбрасывает остаток. Дальше — `"${decadeStart}-е"` и `groupBy { }`.

</div>

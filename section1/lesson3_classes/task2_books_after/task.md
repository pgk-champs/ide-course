# Книги после года

Заверши `booksAfter` — оставь книги, изданные в указанном году или позже,
и отсортируй результат по году издания по возрастанию.

Пример:
```
val library = listOf(
    Book("Дюна", "Герберт", 1965),
    Book("Кобзарь", "Шевченко", 1840),
    Book("Мастер и Маргарита", "Булгаков", 1967),
)
booksAfter(library, 1900) -> [Book("Дюна", "Герберт", 1965), Book("Мастер и Маргарита", "Булгаков", 1967)]
booksAfter(library, 2000) -> []
```

<div class="hint" title="Фильтр + сортировка">

`filter { }` оставляет нужные книги, `sortedBy { }` сортирует список по
выбранному полю. Их можно применить одну за другой.

</div>

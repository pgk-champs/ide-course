# Уникальные авторы

Заверши `uniqueAuthors` — верни набор (`Set`) имён авторов без повторов.
Если у автора несколько книг в списке, в результате он встречается один раз.

Пример:
```
val library = listOf(
    Book("Дюна", "Герберт", 1965),
    Book("Мессия Дюны", "Герберт", 1969),
    Book("Кобзарь", "Шевченко", 1840),
)
uniqueAuthors(library) -> {"Герберт", "Шевченко"}
uniqueAuthors(emptyList()) -> {}
```

<div class="hint" title="Как получить набор без повторов?">

`map { it.author }` соберёт список имён (с повторами), а `.toSet()`
превратит его в набор уникальных значений.

</div>

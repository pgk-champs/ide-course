# Классы и коллекции

Коротко, для памяти — полная глава с разбором `data class`, `List`/`Map`/`Set`
и `when`: [pgk-champs.github.io/platform → Классы и коллекции](https://pgk-champs.github.io/platform/docs/mobile/classes-collections)

- `data class` — чертёж для группы связанных полей: `data class Book(val title: String, val year: Int)`.
  Кроме полей, слово `data` бесплатно генерирует `toString()`, `equals()` и `copy()`.
- `List<T>` — упорядоченный список, может содержать повторы.
  `Set<T>` — набор уникальных значений, повторы схлопываются.
  `Map<K, V>` — пары «ключ → значение».
- `filter { }` оставляет элементы по условию, `map { }` — превращает каждый
  элемент во что-то новое, `sortedBy { }` — сортирует по выбранному полю,
  `groupBy { }` — раскладывает элементы по ключу в `Map`.
- `when` — замена длинной цепочке `if / else if`, особенно хороша с
  диапазонами (`in 1..10`) и несколькими вариантами в одной ветке.

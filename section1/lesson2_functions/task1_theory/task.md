# Функции и лямбды

Коротко, для памяти — полная глава с разбором по символам и тренажёрами:
[pgk-champs.github.io/platform → Функции и лямбды](https://pgk-champs.github.io/platform/docs/mobile/functions-lambdas)

- Сигнатура функции: `fun name(param: Type): ReturnType { ... }`.
  Если тело — одно выражение, можно короче: `fun square(x: Int): Int = x * x`.
- Параметр по умолчанию (`default argument`) освобождает от передачи
  аргумента, если чаще всего он один и тот же: `fun greet(name: String = "гость")`.
- Именованный аргумент (`named argument`) — передаёшь параметр по имени,
  а не по позиции: `greet(name = "Аня")`. Особенно полезно, когда параметров
  несколько и не все нужно менять.
- Лямбда — функция без имени, которую можно передать как значение:
  `{ x: Int -> x * 2 }`. Функция, которая принимает или возвращает другую
  функцию — функция высшего порядка (`higher-order function`).

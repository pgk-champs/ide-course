# PGK Champs: Kotlin с нуля

Курс в формате JetBrains Academy — теория и задачи с автопроверкой прямо в
IDE (Android Studio / IntelliJ IDEA). 1 секция «Основы Kotlin», 4 урока по
главам платформы, в каждом — конспект и 3 практические задачи с тестами.

- Урок 1: Переменные и типы
- Урок 2: Функции и лямбды
- Урок 3: Классы и коллекции
- Урок 4: Финальный мини-проект — турнирная таблица

Полная теория с тренажёрами и разбором по символам — на платформе:
https://pgk-champs.github.io/platform/

## Как студенту установить и открыть курс

1. **Установи плагин.** В Android Studio или IntelliJ IDEA:
   `Settings/Preferences → Plugins → Marketplace` → в поиске введи
   **JetBrains Academy** → Install → перезапусти IDE.
   (Плагин раньше назывался EduTools — если находишь по старому имени в
   старой версии IDE, это тот же плагин.)
2. **Открой курс.** На стартовом экране IDE (Welcome Screen) нажми
   **Get from VCS**, вставь ссылку на этот репозиторий
   (`git@github.com:pgk-champs/ide-course.git` или HTTPS-адрес) и нажми
   Clone. Плагин сам узнает `course-info.yaml` в корне и откроет проект как
   курс, а не как обычный Gradle-проект.
   Альтернатива — сначала `git clone` обычным способом, потом в IDE
   `File → Open` и указать папку репозитория.
3. **Реши первую задачу.** Слева — дерево курса (секция → урок → задача).
   Открой первую задачу, почитай `task.md` в панели курса, впиши решение
   вместо `TODO("реализуй")` в видимый `.kt`-файл и нажми **Check** —
   плагин прогонит тесты из невидимого `test/`-файла и покажет результат
   прямо в IDE.
4. Теоретические задачи (конспект + ссылка на главу платформы) тестов не
   требуют — открой, прочитай, жми Check, чтобы перейти дальше.

## Как проверить задачи без плагина (просто Gradle)

Из корня репозитория:

```
./gradlew test
```

Каждая папка задания — отдельный Gradle-модуль (так же, как их видит сам
плагин). Прогнать одно задание отдельно:

```
./gradlew :section1-lesson1_variables-task2_temperature:test
```

Свежескачанный курс — `TODO("реализуй")` везде, поэтому `./gradlew test`
на нём проваливается: это стартовое состояние, а не поломка.

## Что нужно докликать владельцу в Course Creator (если нужен архив/маркетплейс)

Формат курса — открытый YAML (`course-info.yaml`, `section-info.yaml`,
`lesson-info.yaml`, `task-info.yaml` + `task.md` + `src`/`test`), поэтому
весь контент этого репозитория сгенерирован программно и открывается прямо
из GitHub через **Get from VCS** — отдельный шаг «собрать курс» не нужен.

Ручной шаг в IDE понадобится только если захочется:

1. **Выложить курс на JetBrains Marketplace.** Открой репозиторий в IDE с
   установленным плагином → правой кнопкой на корне проекта →
   **Actions on "Course"** (или пункт меню Course Creator, в зависимости
   от версии плагина) → **Upload Course to Marketplace** — понадобится
   аккаунт JetBrains и логин через плагин. Локально это не проверить без
   реальной публикации, поэтому шаг оставлен владельцу.
2. **Проверить курс глазами студента внутри IDE** — открыть теоретические
   задачи, посмотреть, как рендерится `task.md` (HTML/Markdown-разметка,
   `<div class="hint">`), убедиться, что панель курса и порядок уроков
   выглядят так, как задумано. Это UI-проверка, автотестами не покрывается.
3. **При необходимости — экспорт архива курса** (`.zip` для офлайн-раздачи
   не через Marketplace): в Course Creator меню — **Export Course
   Archive**. Тоже требует открытого в IDE проекта, программно не
   вызывается.

## Структура репозитория

```
course-info.yaml            метаданные курса (название, язык, содержимое)
settings.gradle.kts         каждая папка с src/ — отдельный Gradle-модуль
build.gradle.kts            общая настройка Kotlin + JUnit для всех модулей
section1/
  section-info.yaml
  lesson1_variables/
    lesson-info.yaml
    task1_theory/           теория: task.md + src/Notes.kt (без тестов)
    task2_.../               задача: task.md + src/Solution.kt + test/Tests.kt
    ...
  lesson2_functions/ ...
  lesson3_classes/ ...
  lesson4_project/ ...
```

## Платформа

Полный курс (теория, тренажёры, разбор по символам) — на
https://pgk-champs.github.io/platform/. Задачи здесь — по мотивам практик
`track-mobile-01`/`track-mobile-02`, но не дословно: домены и формулировки
другие, чтобы решения одного формата не гуглились по другому.
